# ai-womens-safety-risk-prediction
AI-powered women’s safety application that uses GPS location, risk prediction, and SOS emergency alerts to help users identify potentially unsafe areas and share their live location with trusted contacts.
🛡️ SafeHer AI – Women’s Safety and Risk Prediction System

📌 About the Project

SafeHer AI is an intelligent women’s safety application designed to help women identify potentially unsafe areas and respond quickly during emergencies. The system combines AI-based risk assessment, GPS location tracking, and emergency SOS features to support safer journeys.

The application aims to help users understand location-based risks and share their live location with trusted contacts when they need assistance.

✨ Key Features

AI-Based Risk Prediction: Assesses potential safety risks in different locations.

GPS Location Tracking: Helps identify the user's current location.

Emergency SOS Button: Provides quick access to emergency assistance.

Live Location Sharing: Supports sharing location details with trusted contacts.

Safety Alerts: Helps users stay aware of potentially risky areas.

User-Friendly Interface: Designed for easy access during stressful situations.

⚠️ Limitations

This project is a prototype. Risk scores may use sample data and should not be treated as validated AI predictions. Emergency alerts and live location sharing require proper integration and testing before real-world use.
